## PowerGUI Studio
A browser-based visual designer for building Windows Forms interfaces and exporting them as PowerShell scripts.

PowerGUI Studio lets you design a form by placing and arranging controls on a canvas, editing their properties and events, and adjusting the layout. It generates a live PowerShell script that you can copy or export as a .ps1 file. The project is implemented as a standalone HTML page: PowerGUI.html.
